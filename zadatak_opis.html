Praktični zadatak: CSS Flexbox — Landing stranica IT agencije

Razred: 3. razred, smjer: Tehničar za računalstvo Tema: CSS Flexbox layouti Oblik rada: Individualni rad Trajanje: 45 minuta

1. Ishodi učenja

Po završetku zadatka učenik će moći:
  • primijeniti display: flex na kontejner i razumjeti ulogu flex kontejnera i flex stavki
  • koristiti justify-content i align-items za pozicioniranje elemenata u jednoj osi
  • izraditi responzivni višestupčani prikaz kartica pomoću flex-wrap
  • organizirati navigacijsku traku bez pozicioniranja s float ili position
  • strukturirati višesekcijski layout jedne web stranice primjenom Flexboxa

2. Scenarij zadatka

Zaposlen/a si kao junior web developer u IT agenciji. Voditelj projekta dao ti je zadatak: izraditi landing stranicu za fiktivnu IT tvrtku TechNova d.o.o. Tvrtka pruža usluge web razvoja, mrežne administracije i IT podrške.

Dizajner je dostavio žičani model (wireframe) stranice (vidi shemu ispod). Tvoj zadatak je implementirati ovaj layout isključivo pomoću CSS Flexboxa — bez CSS Grida, bez float, bez position: absolute.

Važno: Korištenje float, CSS Grid ili apsolutnog pozicioniranja za postizanje layouta rezultirat će odbitkom bodova.

4. Upute i zadaci

Dobio/la si polazne datoteke index.html i style.css. HTML je potpuno napisan. U CSS datoteci su označena mjesta koja trebaš popuniti s odgovarajućim Flexbox svojstvima.

Proučite HTML strukturu, pa za svaki kontejner dodajte tražena CSS svojstva:

# Dio stranice CSS klasa Što trebate postići Vrsta
1 Navigacijska traka .navbar Logotip lijevo, linkovi u sredini, gumb desno — sve u jednom redu, vertikalno centrirano OBAVEZNO
2 Hero sekcija .hero Sadržaj (naslov + gumb) potpuno centriran — i horizontalno i vertikalno unutar sekcije OBAVEZNO
3 Hero sadržaj .hero-sadrzaj Naslov i gumb složeni u stupac, poravnati prema centru OBAVEZNO
4 Mreža kartica usluga .usluge-mreza 3 kartice u redu, jednako raspoređene, s prelaskom u novi red na manjim ekranima OBAVEZNO
5 Unutar svake kartice .kartica Ikona, naslov i tekst složeni u stupac, sadržaj centriran OBAVEZNO
6 Podnožje .footer Copyright lijevo, navigacijski linkovi desno — razmak između space-between OBAVEZNO
7 Footer navigacija .footer-nav Linkovi u redu s razmakom između njih NAPREDNA
Savjet: Pokreni datoteku u pregledniku i koristite DevTools (F12) → Inspect → Layout kako biste vizualizirali flex kontejnere i osi.

5. Što predaješ

  • Datoteka index.html — HTML ne mijenjaš
  • Datoteka style.css — s popunjenim svim /* TODO */ mjestima
  • Snimka ekrana (screenshot) gotove stranice u pregledniku
  • Napredna opcija: Kratki komentar u CSS-u iznad svakog bloka — objasni zašto si odabrao/la koje vrijednosti
